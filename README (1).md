# HigherIncomeJobs – Driver Jobs Landing Page

A clean, professional CPA landing page for US Driver Job opportunities.

## Live Site
After deploying, your site will be live at:
`https://YOUR-USERNAME.github.io/higherincomejobs`

## How to Deploy on GitHub Pages

### Step 1 — Create a GitHub Account
Go to [github.com](https://github.com) and sign up for free.

### Step 2 — Create a New Repository
- Click the **+** button (top right) → **New repository**
- Repository name: `higherincomejobs`
- Set to **Public**
- Click **Create repository**

### Step 3 — Upload Your Files
- Click **uploading an existing file**
- Drag and drop `index.html` and `README.md`
- Click **Commit changes**

### Step 4 — Enable GitHub Pages
- Go to repository **Settings**
- Click **Pages** (left sidebar)
- Under **Source** → select **Deploy from a branch**
- Branch: **main** → folder: **/ (root)**
- Click **Save**

### Step 5 — Your Site is Live!
Wait 1–2 minutes, then visit:
`https://YOUR-USERNAME.github.io/higherincomejobs`
